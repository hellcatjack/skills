# Approved Reference Sheets

Use the relevant sections when an item has multiple views, a fitted component, or an existing sheet or gallery to revise.

## Select sources by view and feature

For each affected panel, identify its current approved file, version, orientation, pose and accepted features. In a composite, record the source crop and the panel's position and size. A user-selected reference can supersede one projection in an otherwise approved master. Apply that decision to the named projection. A perspective sketch approved for a gap or an opening supplies evidence for that feature only.

## Calibrate proportions and fit

1. Choose a visible reference for each shared dimension. For example, use Top for length and width, Side for the approved profile, and End for an opening. Align the centerline or contact plane and compare the subject extents, excluding page margins and labels. Scale each panel uniformly. Before treating the sheet as a dimensional reference, [cross-check all three axis ratios](orthographic-dimensions.md#2-check-whether-one-object-can-satisfy-the-views). If the approved views disagree, identify the affected projections and the physical difference. Request a separate design decision if the intended handoff requires resolving that discrepancy.
2. When the fit depends on another item, use its designated asset, version, units and pose. Include protrusions and supports in its projected bounds. For several identical items abreast, the opening includes the width of every item, the gaps between them and the clearances at both edges. For a row of N items with equal clearances, divide the spare width by N + 1. Use a plan for total capacity and a section for vertical clearance when those questions are in scope. A static fit establishes clearance in the measured pose. Movement through an opening needs its own evidence if requested.
3. Distinguish a measurement from the adopted design dimension. Record the scale reference, named landmarks, measured offsets and any user-authorized modeling choice such as placing paired components symmetrically. Reopen the delivered image and measure the visible landmarks against the same reference. Report pixel tolerance when converting a painted edge to physical units. For rigid opposing views, also apply the [silhouette check](top-ventral-outline.md) and inspect which surface features are visible from each side.

## Revise a sheet and publish it

Start a versioned draft from the approved sheet. Place the approved replacement at the recorded crop, scale and location. Update its source label and the sheet version. For a corrected master, identify which view governs each changed proportion. If a panel must keep its artwork, compare the saved panel with its source at the registered scale. On a one-panel replacement with fixed layout, a pixel difference outside the replacement and its revised labels should be zero.

Approval of a single view makes it eligible for use on dependent sheets. Show each revised sheet for adoption and keep the current index on its published versions during review. When the user adopts the sheets and requests publication, record the decision against the files they saw. Use a file hash when the project tracks image identity. Update the card, thumbnail, enlarged view, full-size link and any standalone view cropped from a replaced sheet. Open the index and check the displayed versions, linked images and crop framing.

## Example for a public guide

Use fictional names and independently chosen dimensions when illustrating a workflow drawn from a private project.

Consider a fictional benchtop recorder with two removable cartridges.

- The concept sketch establishes the slot layout. With two 90 mm cartridges in a 240 mm opening, three equal clearances of 20 mm fill the remaining width. Check the gap between the cartridges and the gap at either wall.
- Use the Top outline for the recorder’s width and depth. Match the Front panel to that width and the Side panel to that depth. Record which view establishes the height.
- If the two indicator lamps move to an approved spacing of 120 mm, replace the Front panel using that drawing. Compare the other panels against the previous sheet, then publish the sheet to the index after approval.
