# 从艺术效果图到 Blender 母版

交付一份能打开、能编辑、能对照原图指出哪些部位已还原的母版。单件产品、建筑、载具、角色和带机构的装配都可走这条流程。由参考类型、物体造型和本次交付范围决定读哪些子技能。

## 安装与可选扩展

在 Codex 项目中，将完整的 `art-to-blender-master/` 子目录放入 `.agents/skills/`，保留 `references/` 与 `scripts/`。核心流程可独立使用。制作母版需要能运行 Blender 的环境；包内轮廓比较脚本使用普通 Python，可在该解释器环境中运行 `python -m pip install Pillow numpy` 安装依赖。

需要专业子技能时，可按任务选用 RobLe3 的 cc-blender-skill v1.4.0。[第三方来源、安装与分工](references/routes.md#来源与安装)

## 先判断从哪一步进入

- **新建或从头重制**：读参考，定尺度与机位，建立新的体块。用户指定从头制作时，在新场景中生成外形，只引入明确要继承的机构、相机、材质等内容，并在交付时列明。
- **已有母版修形**：打开正确的磁盘版本，先在反馈截图的机位复现偏差。记下要保护的尺寸、部件、动作和机位，从现有模型或其生成源产出候选版本。
- **分段精修或全件覆盖**：从[分段复核与修正白模](references/section-review.md)进入，记录各表面的证据，再用俯视、端视和成对斜视修正接缝收尾、折角与凹槽。
- **只做评审或设计确认**：按委托交付量图、差距清单、设计图或白模，到约定节点结束。已有批准继续有效。
- **项目环境**：先核对当前项目指令、实际 Blender 版本、目标文件及共享资产约定。需要选子技能时查[技能分工](references/routes.md)。项目规定的运行器、设备与共享库仅用于相应项目。

## 制作顺序

| 阶段 | 具体工作 | 进入下一阶段的依据 |
| --- | --- | --- |
| 1. 读图与立项 | 把主效果图、正交图、状态图、局部图分配给各自问题。列部件数量、连接对象、可拆件、遮挡和未知面。标明哪个来源裁定造型，哪个来源裁定尺寸或机构。 | 留下可追溯的参考清单、冲突决定及尺度依据。 |
| 2. 量图与定相机 | 正交图标轴、定等比尺度、量站位和截面。透视图用稳定地标与白模拟合相机，再从像素回推受约束的三维棱线。保存原图像素和配准记录。 | 用固定相机把白模投回原图。能解释主要轮廓、负空间及内部折线。详见[量图与配准](references/registration.md)。 |
| 3. 建主形体 | 以可识别的部件、站位、切线和接合方式生成几何。需要再生的资产把量值和造型决策写入设计表或生成脚本；雕刻和手工曲面保留可编辑源及关键阶段。 | 用无材质体块检查主视角和能约束深度的其他视角。结构错误先回到地标或截面。详见[造型与装配](references/form.md)。 |
| 4. 表面与机构 | 稳定主形后再做 UV、材质、真实开口、受力连接和表面细节。用画面里的尺度线索定缝宽、纹理频率和五金大小。可动件建立局部枢轴、动作表、接触关系。 | 检查斜看和背面、开口内部与运动中间态。固定相机和中性灯下能读出结构。 |
| 5. 迭代 | 在候选文件上建造、检查、试渲。主参考、基线与候选同机位并排，再叠外剪影和指定棱线。若怀疑机位有误，按[机位复核](references/registration.md#机位复核与局部修形)先重拍基线，再决定修形量。复查受影响视角和冻结项。 | 按用户给出的目标逐项比较；剩余冲突给出位置、误差和约束依据。 |
| 6. 交付 | 用最终生成源重建，或保存最终艺术源，再从磁盘重新打开。核对外链、帧状态、材质和机构，从这一版出正式图并亲自查看。 | 交付母版、主视对照、针对本次问题的局部证据和实测结论。按需附可重复构建入口。见[验收与交付](references/acceptance.md)。 |

阶段检查由执行者完成。用户或适用项目明确设置的审批点才需要等待确认。相互矛盾的参考已有指定仲裁图时，直接记录取舍；缺少决定且会实质改变设计时，再向用户澄清。

## 验收时问三个问题

1. **尺寸和结构是否成立？** 从求值后的真实几何量包络、截面、开口或行程。固定相机下，再把必须遵守的尺寸包络投影到图上，可解释哪些像素位置本来就无法到达。
2. **从参考角度是否像？** 全局用剪影；局部用同名棱线、折角、窗沿、负空间及截面。优先报告用户点名的部位。出现遮挡就限定可见区域，用对照状态或其他视角补证。
3. **换视角、换状态还成立吗？** 围绕实体检查接缝、侧壁、背面和真实腔体。动画保留任务还要逐帧复核旧版与新版。对静态单图可标明推断区域，交付相应角度的实际渲染。

已具备同画幅配准蒙版时，可直接使用本包的[固定配准比较工具](scripts/compare_registered.py)，支持整图 IoU、共同可见区、局部开放折线及旧版回归。默认报告只保留输入角色和测量结果。指纹记录须显式启用本地溯源。详见[输入约定和命令](references/acceptance.md#固定配准比较工具)。
