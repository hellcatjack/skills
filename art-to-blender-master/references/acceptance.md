# 从候选模型到可复核母版

## 构建与证据链

- 先查看实际场景及磁盘文件；识别已有生成脚本、受保护部件/动作、外部库和项目指定运行器。脚本化项目从同一生成源构建候选。手工艺术源保留原有层次、修改器和可继续编辑的资产。
- 量图与报告可用外部 Python，建造、读取求值网格和渲染用具有相应能力的 Blender 环境。核查两个解释器的实际依赖。共用脚本使用按资产、候选或运行区分的输出目录/日志，记录退出状态；失败的阶段和可能陈旧的图件对应到具体候选。
- 白模对照通过后逐层加细节。修订优先在候选副本或可回滚版本上完成；复核与原版使用同一配准。源文件指纹供明确启用的本地溯源使用。根据本次任务决定保留哪些草稿。

## 三种检查

| 证据 | 做什么 | 判断结果时留意 |
| --- | --- | --- |
| 实体与装配 | 在指定状态展开实例、应用求值变换和修改器，再量尺寸、计数、截面、孔深和间隙。检查退化面、绕向、重复共面、材料槽和实际安装。 | 对应当封闭的体逐网格岛查边的相邻面和朝向；布片、叶片、贴花等有意的单面结构单列。闭合网格仍可能堵住真实开口，必要时从多个位置射线取样或剖切。 |
| 运动 | 比对起止及途中姿势，检查动件与静件、动件之间的干涉，只豁免具体设计接触对及其适用姿态。要保留既有动作时逐帧比对两版父子求值后的世界变换、关键事件和可见性。 | 逐整数帧通过只能证明采样时刻。薄壁、快速运动和连续净空要求应增加子帧采样或做扫掠检查；完全包含的穿透需占用/内部点检查。 |
| 视觉还原 | 在同一画幅并排放参考、基线和候选，叠外轮廓与同名地标。主图、实际有依据的正交视图、反馈部件的近景分别查看。 | 先看主次体量、负空间及棱线，再看材质和光照。细节不足时用近景检查真实层次。参考与成片的光晕、阴影或景深会改变可见边界。 |

碰撞距离、接触容差和倒角尺寸应和模型物理单位一致。若每 Blender 单位等于 `s` 米，则长度容差在模型中为 `米数/s`，面积阈值相应除以 `s²`。带非均匀缩放、蒙皮或实例的对象应在求值后的世界空间量取。

## 派生结构的独立验收

共享一个参数的部件可能一起偏移，装配仍能闭合。为本次改动选择独立于生成公式的期望值，再从重新打开的候选文件读取实际结果。例如固定机位后，把候选开口的四角投回批准图上的同名地标，量其相对原始母版固定接口的站位。对通行要求，沿约定路径移动尺寸已有依据的装载物包络，量求值网格的最窄净距，记录位置、姿态和采样范围。重算构建脚本的输入只能说明参数彼此一致。

局部修订在同一配准下分别报告目标部位的前后误差、其他受影响视角的变化，以及保护件与原母版的比对结果。像素误差写明分析画幅和裁区，几何距离写明单位。把某个视角的退步列在改善项旁，注明仍有差异的部位。

## 固定配准比较工具

[scripts/compare_registered.py](../scripts/compare_registered.py) 使用普通 Python、Pillow、NumPy。每次处理一个视角。视角与棱线使用可公开的描述名，可用中英文字母、数字、空格、点、下划线、连字符及圆括号。输入准备如下：

- 先用保存的相机、状态、画幅和像素变换，把参考及各版求值几何映到同一原图像素网格；变换蒙版用最近邻。本工具只比较传入的数据，不能从 PNG 判断机位是否相同。把相机/配准记录随结果保留。
- 输入为单通道蒙版，如 L 模式 PNG。255 表示属于物体，0 表示背景，阈值为 128。线稿应先变为完整轮廓或只用对应的地标/边线评价。遮挡可用同尺寸的 `--valid`，白为可比较，以同一掩码裁掉所有版本。参考有效区至少包含一个前景像素。
- 可选的 `--features` 是 JSON 列表。每行给出唯一名称、参考折线、候选折线；启用基线时还需给基线折线。点按边顺序排列，坐标为原始画布像素中心，左上为原点。闭环显式写 `"closed": true`。遇遮挡，把可见段拆成不同名字的开放折线。坐标应来自原图描线和真实网格投影。

例如量抽屉的一条拉手内沿：

```json
[{"name":"handle-inner","closed":false,
  "reference":[[20,40],[52,40],[58,46]],
  "baseline":[[20,43],[52,43],[58,49]],
  "candidate":[[20,41],[52,41],[58,47]]}]
```

```text
python scripts/compare_registered.py --view front --reference ref.png --baseline old.png --candidate new.png --valid visible.png --features edges.json --out review/front
```

命令中的脚本路径相对于本技能目录，数据路径可用绝对路径。首次建模可省去 `--baseline`；其余可选项按实际证据使用。输出 `metrics.json` 和 `overlay.png`。各视角用独立结果目录。叠图从左到右是基线（如有）、候选，金线为参考、青线为该版模型，收益见 JSON。

默认报告按角色列出输入，每个角色对应一个空对象。仅在命令末尾显式加上 `--local-provenance` 时，才为各输入计算并记录 SHA-256。两种模式都省略输入路径与文件名。需要分享已有溯源报告时，可另选输出目录，以默认模式重新生成。视角名、棱线名和叠图中的可见设计会随产物公开，请按分享范围选用。其他工具生成的配准记录或报告应另行检查。

报告包含掩码交并比、有效像素数、外接框和质心。每条棱线约每像素按弧长取样，计算两条折线双向的平均点到线段距离，单位为原图像素。需要 P95、边界 F1 或特定尺寸容差时另行报告并说明容差和分母。不同分辨率、蒙版范围、参考版本及校准所得数字分别标注。接近描线/栅格误差或只有一个像素变化时，报告实际精度。

## 回归、停止与交付

1. 复现反馈，指出误差属于相机、数量、截面/棱线、连接、纹理还是外观。用可读的对照图把它定位到部件。修改生成参数或艺术源，复测目标并复查相关旧指标。
2. 若指标停滞而肉眼仍见差异，换能揭示原因的观测，如剖面、铰轴、开口深度或有序折线。若参考超出锁定包络的投影，可量理论可达边界和残差；如实列明冲突。若需要更改用户锁定的约束才可继续，交给用户决定。
3. 最终脚本、模型、图件和报告应属于同一候选。重新打开交付文件，确认纹理已打包或共享库路径有效，实际渲染主图、必要的辅助视角及状态图。查看输出图并记录已跑/未跑项目、实测结果、残留误差和推断。审批约定存在时按该约定交付。
4. 常用交付是一份可编辑 `.blend`、主参考与成片对照、相关量图/检查记录及简短的复现说明。保留输入设计表和项目需要的生成脚本。若交付包含导出物，从实际导出的文件复查本轮涉及的网格、独立变换、材质分区和代表姿态。有多级细节时检查对应视距下实际显示的版本。源场景与导出结果分别记录，性能结论取自目标运行环境的测量。
