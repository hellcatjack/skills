# 把参考变成几何约束

## 选图和记录

按问题分配参考优先级。主效果图常决定外形、层次、材质和氛围；已确认的尺寸图决定实体包络、孔径或行程；状态图能区分本体、可拆装载物及其遮挡。用户指定某一侧视或局部图时，记录它具体覆盖哪些特征。图内生成的文字标注需和可信尺寸核对。

用一张表或现有设计文件留下以下数据，简单资产可合并记录：

| 项目 | 需要能重现的内容 |
| --- | --- |
| 图与坐标 | 文件及版本、主视/正交/局部/状态、原图宽高、裁切矩形、像素原点和轴向。 |
| 尺度 | 已知长度及来源、两端的像素坐标、米或其他单位与 Blender 单位的换算、世界原点、正面和上方。没有绝对尺寸时使用相对单位；门高等间接线索标为估算。 |
| 部件及地标 | 同名 ID、所属部件与状态、视图、点或有序折线像素坐标、对应站位/三维点、可见性。直接量取、推断和用户给定的数值分别标记。 |
| 冲突 | 冲突的两个来源和数值、采纳项、理由、对哪些视图或部件有影响。附带描线或图像本身的不确定度。 |

例如折叠椅的展开图和折合图一起使用时，分别标记座板前角、铰轴中心、支脚接地点。铰轴跨状态固定，接地点随状态改变。用独立的点表可避免把折合的脚架误认成第二条支撑梁。

## 正交图

逐视图裁切，清除文字、标尺和孤立背景，核实左右手、镜像及前后关系。封闭实体用面积蒙版；门洞、把手内孔、开敞框架的负空间按目标保留。先从可靠锚点计算像素/单位，再叠物理网格。记录关键站位沿横向、竖向的上下缘、开口、折点、数量与间距。

不同视图共用同一组实体尺寸，各自允许委托所需的等比缩放和平移。比较反推出的高宽长。若顶图和侧图对同一结构报出不同的站位，应标明各自误差与采纳依据。独立把每张剪影拉伸至同一外接框，只能用于专门标注的归一化形状诊断。

## 透视主图或单张效果图

1. 用视线方向、平行边消失点、圆口投影椭圆和稳定转角估计相机。尽可能选跨深度、分布在画面各处的地标，保留几个未参加拟合的点作复核。只给一张图时，焦距、距离和局部深度通常不能同时唯一确定。
2. 白模上投影地标，先解方位、俯仰、滚转、焦距或正交宽度、平移和镜头偏移；回看近/远侧大小关系和透视收缩。把画幅、像素宽高比、相机世界变换、投影、裁切/配准矩阵、目标帧、蒙版定义和用到的锚点一起存下。
3. 已知所在设计平面的棱线可反投影。对射线 `o + t·d` 与过点 `p`、法向 `n` 的平面，`t = dot(n,p-o)/dot(n,d)`。检查分母接近零和交点落在相机背后的情形。未知深度用多视图、对称或量到的截面约束，记录假设。
4. 拟合结束后锁相机。同一校准用于原版与所有候选；若发现校准本身错误，另存校准并在新校准下重测所有版本。核对三维矩阵、画幅和像素映射，仅靠相同相机名称不足以复现。
5. 光晕、手部或物体遮挡时，为各版本冻结同一个有效区。被遮的棱线分成各自可见的开放折线；完整外形可用同机位另一状态补证。若只有单图，可补渲侧后视检查结构，并将深度或背面标作推断。

## 机位复核与局部修形

当已对齐的正视图与斜视图给出相反结论，或局部误差随视角明显变化，先保留编辑前的模型与原机位。用目标部件以外、跨前后景的稳定棱线或转角复核投影，并用未参加拟合的地标检验。另存复核机位，在同一原图坐标、裁区、可见区和模型姿态下保留三份记录。

| 模型与机位 | 用途 |
| --- | --- |
| 旧模、原机位 | 复现反馈，记录目标点或棱线相对原画的带符号偏差。 |
| 同一旧模、复核机位 | 与第一份比较，量出仅由配准改变的偏差。若剩余误差已落入描线不确定度，到此结束修形判断。 |
| 新模、同一复核机位 | 修形后与第二份比较，量出几何带来的变化，并在已对齐的独立视图回测冻结项。 |

三份均叠同一原画。标明画幅、误差方向、单位和遮挡范围，整图剪影 IoU 与目标棱线的误差分别报告。缺少旧机位或旧模时，标明可复现的起点，从当前版本建立基线。

## 何时可以开始加细节

在主图上并排查看参考、无材质白模和叠线，至少检查项目关心的内部地标、负空间与尺度。若外轮廓相合但斜面被做成平板，加同机位折线和截面深度检查。若尺寸和图形不能同时满足，把锁定包络投影到同一机位，量参考边落在可达范围外的距离。在此基础上决定几何取舍。
