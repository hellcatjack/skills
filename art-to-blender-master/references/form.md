# 按形体选择建法

先画部件关系和截面，再选网格表示。一个装配常同时需要多种建法。设计表用统一物理单位，构建时集中换算。能由同一轮廓、轴线或母曲面推导的接缝和附件，共用这组数据。

| 参考中可观察的结构 | 建模选择 | 最值得检查的失败方式 |
| --- | --- | --- |
| 支架、家具框架、工业装配 | 用截面沿路径扫掠成梁，按连接面制作插接、端盖和斜撑。相同模块实例化；活动、拆卸或不同涂装的件保留独立变换。 | 用空载/展开参考辨认哪些是主体。查中间支撑落在哪里，孔洞是否贯通。 |
| 产品外壳、折面装甲、建筑幕墙 | 在关键站位放带棱线的截面。共平面的多边形可由三点求平面约束第四点；凹形拆段放样。外贴面沿真实母面裁切、内缩、加厚，再补回边。 | 从斜视比较棱线和折角。单一凸包可能封住凹陷，倒角可能吃掉薄板或改变包络。 |
| 连续曲面、圆滑外壳 | 用截面曲线、细分笼或隐式场描述宽度、高度和曲率，近尖端及高曲率区加密。由同一母面裁出玻璃和门叶，在边界共用采样，补壁、端面、门袋和密封。 | 射线逐环取样要求截面对选定内点是星形；多次相交时改分片/多环或改用等值面。检查轮廓、缝两侧法线和开口截面。 |
| 连续内壳加可拆覆盖件 | 先做连续承力体，按局部表面坐标从壳体派生分块的厚板与回接面。区分维护缝、结构缝与涂装边。 | 灯光方向变化后仍有真实层次。暗色底衬突出外轮廓时，修回接几何。 |
| 管件、环、镜头、铰链 | 保留局部轴线与旋转剖面。开放通道用环形截面或布尔开口，封闭透镜和端盖按用途独立制作。 | 量多处半径、轴心和开孔截面。用射线或剖切检验可视/可通过深度。 |
| 标志、浮雕、线稿或平面吉祥物 | 分离相接形状，保留内环与负空间，按外轮廓和内孔建面。以侧视或明确假设确定厚度，安排侧壁及背面 UV。 | 从侧后方实际渲染；检查镜像、文字方向、未贴图端面和透明排序。 |
| 角色、软造型或非对称雕塑 | 先建大体量、姿态线和主要平面，再建立细分或雕刻源。用比例点检验关节、接地和脸部特征。有变形需求时安排拓扑环线及代表姿态。 | 单图视差可造成近远肢体不等大。对称、闭合、硬棱和机械装配公差按具体资产选用。 |

## 程序化部件的共同基准

几个部件由同一截面、边线或安装面生成时，在已有设计表或生成脚本里写清该基准取自哪张批准视图、哪个地标或原始母版的哪个接口，注明参数改变时哪些件随动。对局部修形，同时指出需要保留的母版形体、刚性件的局部枢轴和行程。视图未覆盖的背面优先沿用已有批准母版，图纸分歧沿用该资产的仲裁记录。

例如扩大检修口时，壳体切口、框内沿和衬壁起边共用一圈截面。固定在框上的附件随安装面就位。若修订只涉及门框，门叶沿原枢轴和行程回放。一旦新开口与原门叶不相容，标出冲突的边或姿态，按[派生结构的独立验收](acceptance.md#派生结构的独立验收)定位原因。

## 表面、尺度与色材

- 在主图、使用距离和请求的最近机位分别看一次。螺栓、压板、标识、工作灯放在会使用或维护的位置。远看只改变色调的细节可进材质；会改变剪影、遮挡或近景接触影的结构用几何。
- 给贴图确定对象空间尺度、UV 岛、阅读方向和侧壁回接。先修形状与 UV，再调粗糙度、色彩管理、光源大小和曝光。来自照片的颜色参考应辨别固有色和烘入的高光/阴影。
- 锁定共享材质的项目先测试现有材质在目标尺度的效果。需要调整时使用项目允许的实例或局部层。保留材质依赖，交付时检查路径或打包结果。

## 机构与附属件

每个旋转或滑动部件记录局部枢轴、行程、父子关系、驱动方式和可见状态。铰链、刚性门叶及圆环保持刚体；主体截面修改只传递给确实附着的饰件。装配接触要对应实际接口和姿态。静态附件的接合深度、密封缝和倒角按尺度与用途设定，必要时以求值网格校核。

对已有动作的修订，先记录旧文件的动作区间、实际世界变换、约束、时序和可见性。在磁盘候选上重放并和旧文件比较。开闭演示至少包含起始、途中、终止和恢复姿势。干涉与最小间隙的核查方法见[验收与交付](acceptance.md)。
